## 📊 项目关键指标

### 开发资源
```
团队配置: 1前端 + 1后端 + 1UI设计师
开发周期: 6-8周
总工时: 468小时
  ├─ 后端: 232小时 (50%)
  ├─ 前端: 196小时 (42%)
  └─ UI设计: 40小时 (8%)
```

### 技术栈
```
前端: 微信小程序 + Vant Weapp
后端: Node.js (Clawdbot改造) + Express
数据库: MySQL + Redis
AI: 通义千问 (主) / Claude (备)
云服务: 阿里云 ECS + RDS + OSS
```

### 核心功能
```
MVP必须有:
✅ 晨思对话流程 (AI引导反思)
✅ 语音输入
✅ 金句卡片生成
✅ 历史记录查看
✅ 目标设定与AI关联
✅ 朋友圈分享

V1.1迭代:
⏸️ 情绪趋势图
⏸️ 深色模式
⏸️ 数据导出
⏸️ 云端备份
```

## 💡 关键决策点

在开发过程中,你需要做出以下关键决策:

### 决策1: AI模型选择
```
选项A: 通义千问 (推荐)
优点: 阿里云生态,延迟低,中文能力强
缺点: 国际化受限

选项B: Claude
优点: 共情能力强,适合心理对话
缺点: 成本较高,需科学上网

建议: 主用通义千问,备用Claude
```

### 决策2: 金句卡片背景
```
选项A: 纯色渐变
成本: $0 (设计师手工)
效果: ⭐⭐⭐

选项B: 自然纹理
成本: 约$50 (购买纹理素材)
效果: ⭐⭐⭐⭐

选项C: Midjourney生成
成本: 约$200/月 (API费用)
效果: ⭐⭐⭐⭐⭐

建议: MVP用方案A,V1.1升级为方案C
```

### 决策3: 是否裁剪功能
```
如果开发进度紧张,可以延期以下功能到V1.1:
- 情绪趋势图 (节省8h前端 + 8h后端)
- 深色模式 (节省6h前端)
- 云端备份 (节省8h后端)

总计可节省: 30小时 ≈ 4个工作日
```
