# 晨思 APP MVP 原型设计建议

**版本**: v1.0  
**设计理念**: 极简·禅意·温暖  
**参考风格**: 微信极简设计 + 冥想APP的沉浸感

---

## 🎨 设计系统

### 色彩方案

```
主色调 (自然禅意)
├─ 主色 Primary:    #8B7355  (大地棕)
├─ 辅助色 Secondary: #D4C4B0  (米白)
├─ 强调色 Accent:    #E8DCC8  (暖米)
└─ 背景色 BG:        #F5F5F0  (淡米)

文字颜色
├─ 主文字: #2C2C2C  (深灰)
├─ 次要文字: #8B8B8B  (中灰)
└─ 辅助文字: #B8B8B8  (浅灰)

功能色
├─ 成功/积极: #7FA650  (抹茶绿)
├─ 警告: #D9A441  (琥珀黄)
└─ 错误/消极: #C97064  (砖红)
```

### 字体规范

```
标题字体: PingFang SC Medium
正文字体: PingFang SC Regular

字号体系:
├─ H1: 28px (页面标题)
├─ H2: 24px (区块标题)
├─ H3: 20px (卡片标题)
├─ Body: 16px (正文)
└─ Caption: 14px (辅助文字)
```

### 圆角规范

```
├─ 小圆角: 8px (按钮/输入框)
├─ 中圆角: 16px (卡片)
└─ 大圆角: 24px (模态弹窗)
```

## 🎭 微动效设计

### 1. 呼吸动画
```javascript
// 参数
duration: 4秒/次 (2秒吸气 + 2秒呼气)
scale: 0.8 → 1.2 → 0.8
opacity: 0.6 → 1.0 → 0.6
color: 从主色渐变到强调色

// 反馈
- 吸气时震动 (轻微)
- 呼气时震动 (轻微)
```

### 2. 打字机效果
```javascript
// AI回复逐字显示
speed: 50ms/字
cursor: 闪烁光标
sound: 可选打字音效 (可关闭)
```

### 3. 卡片翻转动画
```javascript
// 点击卡片翻转查看背面
transform: rotateY(0deg) → rotateY(180deg)
duration: 600ms
easing: ease-in-out
```

### 4. 完成反馈
```javascript
// 完成晨思后的庆祝动画
- 屏幕飘落花瓣/星星 (Lottie动画)
- 播放"ding"音效
- 震动反馈
- 显示"已坚持X天"徽章
```
